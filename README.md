# Rasa Tizdast

### Frontend Developer · React · Next.js · TypeScript

I build responsive web applications that bring clarity to complex product and operational workflows. My recent work spans Persian right-to-left (RTL) product discovery, interactive planning tools, and clinic-management software.

Based in Tehran, Iran.

## Selected projects

### [Farabak Web Platform](https://github.com/rasaTizdast/next-farabak.net-app)

A live, Persian-first platform for discovering security and professional imaging equipment. It brings together a searchable product catalog, guided product selection, project-planning tools, and customer support.

**Highlights**: responsive RTL interfaces, product-advisor workflows, interactive storage and site-fit estimates, and report generation.

**Stack**: Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · Prisma · PostgreSQL

[Live site](https://farabak.net) · [Source code](https://github.com/rasaTizdast/next-farabak.net-app)

### [Sefro Clinic](https://github.com/rasaTizdast/sefro-clinic-pwa)

A progressive web app (PWA) for clinic management, covering patient records, appointments, services, accounting, inventory, and reporting. It supports Persian RTL use and offline workflows.

**Stack**: React 19 · TypeScript · Vite · Tailwind CSS 4 · Django REST Framework

### [Clinic Next App](https://github.com/rasaTizdast/clinic-next-app)

A Next.js front end for catalog and product content, team and company information, and configurable public-site settings. It loads published content from a Django-backed application and provides fallbacks when optional content is unavailable.

**Stack**: Next.js · React · TypeScript · Django REST integration
